# pebble_tides

A Pebble watchapp (C + PebbleKit JS) that shows a day's predicted tides — exact high/low times and a curve — for the nearest Canadian DFO tide station. Optimized for gabbro (Pebble Round 2). See [README.md](README.md) for build/run.
